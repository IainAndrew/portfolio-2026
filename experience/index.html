Senior Software Engineer

Canva (Pexels) · 2021 – 2026 · Remote

Pexels is Canva's free stock photo and video platform. I joined as a frontend engineer on the website and became the engineer the team handed its most important work to, across web, backend, mobile and data.

  • Led delivery of the 2025 programme that moves users from Pexels into Canva: the dual Download / Edit in Canva grid button (a 45% lift in daily click-through from a single launch), Canva-branded inline ads rolled out to every user with localised creative in 18 languages, a custom right-click menu, and deep links that open Canva's editor with the asset already in place. Each change shipped as a controlled experiment with guard-rail metrics; the programme finished the half well ahead of goal and monthly sign-ups to Canva from Pexels roughly tripled.
  • Scoped, architected and built most of The Level Up, Pexels' first photography course: enrolment and progress models and API in Rails, episode unlocking, a video player with chapters, resume and localised captions, and two pipelines, one encoding source video for the web and one running Whisper transcription with AI translation into 27 languages. The first project Pexels engineering and marketing ran together.
  • Took on frontend production reliability as a frontend engineer new to Kubernetes: load-tested and restructured the Next.js server fleet (65% less memory per process), then designed readiness and pre-warm health checks that cut peak response time during deploys by 71%. Frontend servers went from a recurring cause of outages to stable.
  • Built the in-house A/B testing framework when Google Optimize was retired: variant assignment at the edge in Cloudflare Workers with per-variant caching, server-side experiments the old tooling could not run, concurrent experiments and country targeting, and the documentation the team runs experiments from.
  • Drove the migration to schema-validated analytics events (Snowplow and Iglu) with a single type-safe schema package shared by web and mobile, running old and new events in parallel and root-causing every discrepancy before cut-over.
  • Shipped contributor-recognition features end to end: the Winners Wall, which contributors call a favourite page, and the backend data model behind profile achievements, with schema migrations and production backfills, on a reusable theming system the next product was built on.
  • Made AI tooling a team capability: the March 2025 write-up that opened Pexels' adoption conversation and drew engineers from across Canva, weekly knowledge-sharing sessions, the frontend repo's agent configuration on the open AGENTS.md and SKILL.md standards (since adopted by the other Pexels repos), and coaching the team's designer to his first pull request.
  • Around 840 merged pull requests across the frontend (Next.js, React), backend (Rails), mobile (React Native) and edge (Cloudflare Workers) codebases, including running the mobile app's releases.
